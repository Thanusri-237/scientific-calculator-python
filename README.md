# 🧮 Scientific Calculator using Python

A GUI-based scientific calculator developed using **Python and Tkinter**. It provides basic arithmetic operations and scientific functions through a simple, dark-themed graphical interface.

## ✨ Features

- ➕ Basic arithmetic: Addition, subtraction, multiplication and division
- 📐 Trigonometric functions: Sine, cosine and tangent
- √ Square root
- 🔢 Logarithmic functions: `log` and `ln`
- ⬆️ Powers: Square, \(x^y\), \(10^x\) and \(e^x\)
- ❗ Factorial calculation
- 📏 Absolute value
- π Mathematical constants: Pi and Euler's number
- 📐 Degree mode for trigonometric calculations
- 🕘 Calculation history saved in a text file
- ⌫ Clear and backspace controls
- ⌨️ Keyboard input support
- 🌙 Dark-themed graphical user interface

## 🛠️ Technologies Used

- **Programming language:** Python
- **GUI library:** Tkinter
- **Mathematical operations:** Python `math` module
- **File handling:** Python file operations

## 💻 Requirements

- Python 3
- Tkinter (usually included with Python on Windows)

## 🚀 How to Run

1. Install Python from [python.org](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the folder containing the Python file.
4. Run the following command:

```bash
python scientific_calculator.py
```

The calculator window should open.
